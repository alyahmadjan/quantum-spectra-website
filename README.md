# Quantum Spectra Website

A responsive one-page business website for Quantum Spectra.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive design and visual styling
- `script.js` — mobile navigation, reveal animations and dynamic year

## Publish for free with GitHub Pages

1. Create a new GitHub repository, for example `quantum-spectra-site`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/root`, then save.
6. GitHub will provide the public website address.

The website uses Google Fonts from `fonts.googleapis.com`. Everything else is self-contained and has no paid dependencies.

## Customization

The main contact email is set to `alidatainsights@gmail.com` in `index.html`. Change it before publishing if you want to use another business email.
